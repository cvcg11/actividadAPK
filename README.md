# Catálogo Móvil

Aplicación móvil desarrollada con React Native y Expo para la evaluación de Perfil 15%.

## Funcionalidades

- Splash screen e ícono personalizado.
- Pantalla inicial con información del estudiante.
- Navegación hacia el catálogo mediante Expo Router, basado en React Navigation.
- Consumo de Fake Store API con `fetch` y `async/await`.
- Custom hook `useProducts` para aislar la lógica de datos.
- Componente reutilizable `ProductCard` para cada producto.
